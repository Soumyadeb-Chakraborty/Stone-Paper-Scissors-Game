# Stone Paper Scissors Game

A sleek, interactive, and fully responsive web-based implementation of the classic **Stone, Paper, Scissors** game. Play against an automated computer AI that generates completely random choices while keeping track of the live scores!

---

## 🚀 Features

* **Dynamic Visual Feedback:** Watch the status bar change color and drop unique emojis based on whether you win, lose, or secure a draw.
* **Animated Status Message:** Smoothly transitions from status emojis back to the game prompt using JavaScript timing mechanisms (`setTimeout`).
* **Real-Time Scoreboard:** Automatically keeps score for both the user and the computer throughout the game session.
* **Clean UI/UX:** Rounded icons with crisp interactive hover effects and fluid layout alignments powered by CSS Flexbox.

---

## 🛠️ Built With

* **HTML5:** Structured semantic markup utilizing game containers, image nodes, and dedicated score displays.
* **CSS3:** Handled responsive sizing, custom color palettes, modern layout design via Flexbox, and interactive hover properties.
* **JavaScript (ES6+):** Pure vanilla JavaScript driving the game logic, event listeners, array manipulation, and dynamic DOM manipulation.
